# LogiX Lab UI

Từ thư mục `src/`, kích hoạt môi trường Python đã cài `requirements.txt`, rồi chạy:

```bash
python -m lab8.demo_server
```

Mở http://127.0.0.1:8765 và nhấn Ctrl+C trong terminal để dừng. UI đọc benchmark public và chạy shape thật trên dữ liệu public với SQLite và trace tạm, mới cho mỗi lần chạy. Các số liệu chi phí là mô phỏng; đây không phải điểm hidden.
